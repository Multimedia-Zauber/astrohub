# AstroHub Roadmap

## 0.1 Alpha goal

Deliver the first AstroHub version that can be installed, configured, taken into the field, used offline and used to record real observations without data loss.

## Milestone 0 — Foundation

- Repository and project policies
- PHP Core skeleton
- TypeScript Web/PWA skeleton
- Python Science service skeleton
- SQLite persistence
- API conventions
- logging and configuration
- automated test foundation

## 1.0 definition

AstroHub 1.0 does not mean every astronomy feature is complete. It means the Core, data model, plugin interfaces, offline/sync behaviour and public APIs are stable enough for other developers and astronomy groups to build on reliably.

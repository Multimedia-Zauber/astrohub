# AstroHub Providers

Adapters for external or local data sources live here.

Provider categories are capability-based, for example WeatherProvider, SpaceWeatherProvider, SeeingProvider, EphemerisProvider, MeteorProvider, MinorPlanetProvider, SatelliteProvider, GeocodingProvider and LightPollutionProvider.

Provider implementations must expose source/freshness metadata and respect upstream licences and attribution requirements.
